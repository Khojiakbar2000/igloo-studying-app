# Penguin hatch balance study

`penguin-hatch-balance-study.png` is a five-pose ImageGen concept sheet produced with the installed `2dimg2motion` workflow, using IGLOO's approved front-facing penguin art as the character identity reference.

It explores a neutral pose, anticipation crouch, emergence stretch, seated recovery, and wave. It is a visual motion reference only: it is not a frame-accurate sprite animation and is not used by the app. The production character remains `../igloo-penguin-front-gaze.riv`.

`igloo-penguin-front-gaze-edit-rejected.riv` preserves the first keyframe-edit experiment. Although its tracks lint successfully, rendered playback lost the character movement, so it is intentionally excluded from the app. The Rive editor workflow's binary keyframe edit is not reliable enough for this rig without authoring/previewing in the Rive editor.
